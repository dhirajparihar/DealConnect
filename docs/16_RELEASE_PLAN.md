# Release Plan

## Release 0 — Internal prototype
Goal:
Validate:
- tenant model;
- customer registration;
- requirement;
- inventory;
- matching.

No real customer messaging required.

## Release 1 — Pilot
Goal:
3-10 dealers.

Include:
- real OTP;
- WhatsApp;
- customer portal;
- dealer dashboard;
- matching;
- follow-ups;
- monitoring.

## Release 2 — Stabilization
Focus:
- performance;
- reliability;
- security;
- better reporting;
- notification controls.

## Release 3 — Commercial
Add:
- billing;
- plans;
- subscription management;
- onboarding;
- support workflows.

## Release 4 — Scale
Only when metrics justify:
- search engine;
- read replicas;
- worker autoscaling;
- analytics warehouse;
- advanced matching.

## Release 5 — Optional network
Only if there is proven demand:
- cross-dealer matching;
- dealer referral;
- customer portability;
- network marketplace.
